# SPEC-GATE-00 正向用例

## 前提

项目当前 `SPEC-AUTH-01` 基线通过；`.vibe/routes.json` 里至少有一条 `public` 路由。

## 动作

```bash
vibe-check SPEC-GATE-00 --project .
```

内部流程：

1. 先跑一遍 `AUTH-01`，确认基线通过
2. 把 `.vibe` 复制到临时目录，删掉某条 public 路由的 `reason`
3. 在临时副本上再跑一遍 `AUTH-01` —— **必须变红**
4. 清理临时目录

## 期望

退出码 `0`，两条子判定 `PASS`：基线通过、注入后变红。

## 失败含义

注入违规后判定仍然通过，说明**门禁是假的**——这种问题在平时完全看不出来，只有真出事那天才会发现没有任何拦截。
