# SPEC-MCP-02 负向用例

## 动作与期望

1. 服务端**不区分身份**，服务 token 调 `user` 工具直接成功
   → 子判定「服务身份调 user 工具 → 拒绝」`FAIL`，退出码 `1`

2. 服务端**不校验 token**，无身份请求也返回结果
   → 子判定「无身份调用 → 拒绝」`FAIL`

3. MCP 端点不存在（404）
   → 三条调用子判定均 `FAIL`，判定整体红

## 失败含义

第 1 条是这条判定存在的理由：**「服务身份」如果不受限，它就是超级用户**，而它的调用通常不带用户上下文，出事时日志里只有"某个服务"。
