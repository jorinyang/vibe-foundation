# SPEC-STRUCT-01 处方

## 动作

1. **循环依赖**：把循环里被依赖的部分抽成一个更底层的模块（通常是 types / utils），两边都依赖它，而不是互相依赖
2. **方向违规**：三条路
   - 把被依赖的逻辑下沉到更低层
   - 用依赖注入把低层对高层的调用反转成回调
   - 如果确实该反向，把这条边写进 `layers` 声明并说明理由
3. 重跑验证命令

## 判定通过条件

```bash
vibe-check SPEC-STRUCT-01 --project .
```

退出码 `0`。

## 不可自动修复时

若项目尚未分层，把 `layers` 留空即可跳过方向检查（循环依赖仍会被检查）。**不要为了过判定把 `layers` 写成互相全通**——那等于取消分层。
