# SPEC-ENV-01 处方

## 动作

1. 打开 `.vibe/config.json`，在 `envProbe.required` 列出全部必需变量
2. 在服务入口加启动校验：逐项检查必需变量，任一缺失即打印缺失项并 `process.exit(1)`
3. 不要用 `|| '默认值'` 兜底 —— 那会让这条判定永远通过
4. 重跑验证命令

## 判定通过条件

```bash
vibe-check SPEC-ENV-01 --project .
```

退出码 `0`。

## 不可自动修复时

若某些变量确实有合理默认值，把它们从 `required` 里移出，另建一份"可选变量"清单；不要为了过判定而保留默认值。
